เริ่มจากหน้าเว็บ: กดปุ่มหรือช่องในหน้าเว็บจำลองด้านซ้าย แล้วดูว่าคำขอวิ่งผ่านเครื่องไหน ส่งแพ็กเก็ตอะไรไป ได้อะไรกลับ และโค้ดอยู่ไฟล์ไหน บรรทัดไหน ไล่ทีละขั้นด้วยปุ่ม “ถัดไป” โค้ดทุกชิ้นดึงมาจากโปรเจกต์เวอร์ชันของเพื่อน (เวอร์ชันที่เพิ่ม security และไฟล์ .env)

  • เบราว์เซอร์คุยกับ PC1 ที่เดียวหน้าเว็บ, /api/ และ /media/ ใช้ที่อยู่เดียวกันหมด Nginx เป็นคนส่งต่อ จึงไม่ต้องตั้ง CORS
  • PC2 เป็นตัวกลางเบราว์เซอร์ไม่เคยคุยกับ PC3 หรือ PC4 ตรง ๆ ทุกอย่างผ่าน Flask
  • ข้อมูลและไฟล์ภาพอยู่ PC4ฐานข้อมูลเก็บแค่ path เช่น outputs/1_17917.png ไฟล์จริงอยู่ใน pc4-database/storage/
  • รหัสลับอยู่ใน .envPC2 ใช้ DB_TOKEN คุยกับ PC4 และ user:pass คุยกับ PC3 ค่าต้องตรงกันทั้งสองฝั่ง (ดู “การเชื่อมต่อ 4 เครื่อง”)

    การเชื่อมต่อ 4 เครื่อง

    ทุกเส้นมีสองฝั่ง ฝั่งซ้ายคือผู้ส่ง (ต้องรู้ที่อยู่และรหัส) ฝั่งขวาคือผู้รับ (ต้องเปิดพอร์ตและตรวจรหัส) ถ้าค่าสองฝั่งไม่ตรงกัน เส้นนั้นขาดทันที

    ค่าที่ต้องตรงกันสองที่ (เปลี่ยน IP หรือรหัสเมื่อไหร่ ต้องแก้ทั้งคู่)

    ค่าที่ที่ 1ที่ที่ 2

    อาการเมื่อเส้นขาด: PC1→PC2 ได้ 502 Bad Gateway · PC2→PC4 token ไม่ตรงได้ 401 / IP ไม่อยู่ในรายชื่อได้ 403 (หน้าเว็บขึ้น 503) · PC2→PC3 รหัสไม่ตรง dropdown checkpoint ว่าง และสร้างภาพได้ 502 · เช็คทุกเส้นพร้อมกันได้ที่ /api/health

    ถ้าต้องเขียนเองตั้งแต่ศูนย์

    ลำดับการเขียนโค้ด
