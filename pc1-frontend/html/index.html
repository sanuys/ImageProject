ค่าใหม่ของพิกเซลขึ้นกับ ค่าเดิมของพิกเซลนั้นเท่านั้น g(x,y) = T(f(x,y)) ไม่ดูเพื่อนบ้าน — คำนวณค่าใหม่ของ 0–255 ไว้ในตาราง (LUT) ครั้งเดียวแล้วเปิดตาราง

เอาค่าสูงสุดลบค่าเดิม s = 255 − r → ขาวกลายเป็นดำ ดำกลายเป็นขาว เหมาะดูรายละเอียดสีขาวในพื้นดำ

s = c · log(1 + r) โดย c = 255 / log(256) → ยืดช่วงมืดให้เห็นรายละเอียด บีบช่วงสว่าง (ใช้แสดง Fourier spectrum ที่ค่าต่างกันมาก)

เส้นหักมุมผ่าน (r1, s1) และ (r2, s2) — ช่วง r1 ถึง r2 ถ้าเส้นชันกว่า 45° คือยืด contrast ของช่วงนั้น (ต้องตั้ง r1 < r2)

ปรับ contrast อัตโนมัติจาก histogram ไม่ต้องเลือกจุดเอง — ทำบนช่องความสว่าง (Y) ของภาพ สีจึงไม่เพี้ยน

หาค่าต่ำสุด (alow) และสูงสุด (ahigh) ที่มีในภาพ แล้ว ยืดช่วงนี้ให้เต็ม 0–255 แบบเส้นตรง รูปร่าง histogram เหมือนเดิมแค่กว้างขึ้น

นับ จำนวนพิกเซลแต่ละค่า (histogram) → สะสม จากค่าน้อยไปมาก (CDF) → เทียบสัดส่วน กับจำนวนพิกเซลทั้งหมดแล้วขยายเป็น 0–255 → แทนค่า ทุกพิกเซลตามตาราง ได้ histogram กระจายเต็มช่วง

วาง kernel ทับทุกพิกเซล เอา ค่าคูณน้ำหนักแล้วบวกกัน เป็นค่าใหม่ แล้วเลื่อนต่อจนครบภาพ — ขอบภาพเติมด้วยการคัดลอกขอบ (replicate padding)

ทุกช่องใน kernel น้ำหนักเท่ากัน = หาค่าเฉลี่ย → ภาพเบลอ ลด noise (low-pass) คำนวณเร็ว แต่ขอบแตกเป็นบล็อก

ช่องกลางหนักสุด รอบนอกค่อย ๆ เบาลงตาม σ → เบลอนุ่มเป็นธรรมชาติ รักษาขอบได้ดีกว่า Mean (ขั้นแรกของ Canny)

kernel ที่น้ำหนักรวมกันได้ 0 → พื้นเรียบได้ค่าใกล้ 0 ส่วนที่ ค่าเปลี่ยนเร็ว (ขอบ) ได้ค่าสูง (high-pass) แสดงผลเป็น |ค่า| บนภาพเทา

เก็บค่าทั้งหมดในหน้าต่างรอบพิกเซล เรียงจากน้อยไปมาก แล้วเลือกตัวที่ต้องการเป็นค่าใหม่ ไม่มีการคูณ-บวก จึงเรียกว่า non-linear

เลือก ตัวกลาง → ลบ salt & pepper noise ได้ดีที่สุด เพราะค่าสุดโต่ง (0 / 255) อยู่ปลายแถว ไม่ถูกเลือก

หา ค่าเฉลี่ย (จริง ๆ เป็น linear) ใส่ไว้เทียบกับ Median → จุด noise ไม่หายแต่กลายเป็นรอยจาง และภาพเบลอทั้งภาพ

เลือก ตัวน้อยสุด → ส่วนมืดขยายตัว ลบจุดขาว (salt) ได้ = grayscale erosion

เลือก ตัวมากสุด → ส่วนสว่างขยายตัว ลบจุดดำ (pepper) ได้ = grayscale dilation
